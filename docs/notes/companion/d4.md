# D4 — server, test client, discovery, bind plan

- `server.rs`: `bind_plan` (pure, C13), `Link` (TCP; RFCOMM in `bt_win.rs`), `Hub` (UI <-> session threads: auth
  state, the current session, the picture mailbox + STATE / CURSOR slot with a `Condvar`, acks / CONFIG from the
  reader, `want_frame`, `fps`, the `HubEvent` channel and a `wake` callback = `ctx.request_repaint`), `Server`
  (listeners, `stop` joins them), `run_session` (magic, HELLO, BUSY check, `Handshake`, AUTH incl. confirm with
  AUTH_WAIT every second, pairing record, replace-same-tablet, then reader + writer threads), `run_writer` (STATE
  first when it changed, FRAME when a picture waits and fewer than `window` frames are unacknowledged, REFINE when
  idle, CURSOR at most every 33 ms).
- Listeners: non-blocking accept with a 50 ms poll and the stop flag; sessions read with a 100 ms socket timeout, so
  the idle timeout (5 s, 10 s on Bluetooth) and the stop flag are seen within 100 ms.
- Wi-Fi binds `0.0.0.0:port`, which also takes the loopback connections of USB, so USB + Wi-Fi is one listener (two
  listeners on the same port with a specific and the wildcard address are avoided).
- STATE's `surface_w/h` and `pixels_per_point` are taken from the last captured picture once one exists (the UI's
  estimate before that), so the tablet's coordinate mapping always matches the picture it shows.
- `client.rs`: `TestClient` (blocking; HELLO / AUTH incl. the server-MAC check, picture from tiles, auto-ack, input
  helpers with their own `seq`). `discovery.rs`: packets + `Responder`.
- Loopback tests (`server::tests`, `discovery::tests`; every socket on 127.0.0.1 with an ephemeral port): confirm ->
  token reconnect, KEY frame then only the changed 64-px rectangle (decoded and compared), wrong token, wrong code,
  right code, BUSY, VERSION (client 2..3), unknown caps + longer HELLO, PAIRING_CLOSED, garbage magic, confirm with
  AUTH_WAIT then Allow, Deny, the ack window (USB = 2), input order PEN/TOUCH/KEY/TEXT/MODS/ACTION with seq 1..6,
  PING/PONG, same-tablet replace, idle timeout (shortened to 1.5 s by the test config), UDP discovery on 127.0.0.1.
  Ran three times in a row: stable.
